# 📊 Power BI Sales & Profit Dashboard

This project analyzes sales and profit data using interactive Power BI visuals like bar charts, line charts, pie charts, and maps. Key insights include top-performing regions, sub-categories, and trends across years.

## 🔍 Key Insights:
- 📍 **West** region has the highest sales
- ❗ **Tables** show negative profit
- 📈 Sales trend increased from 2014 to 2017
